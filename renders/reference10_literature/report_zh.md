# 文献十通道参考、reset 与固定手桨约束

本版以原始数字化文献曲线为底稿。桨六角度、滑座、左右肘角、T6 竖直倾角共十个目标直接来自来源曲线及可审计变换；辅助全身 IK 只用于诊断、选择侧后方屈肘姿态和渲染。原始数据文件 SHA256 未变。

## 十通道调整

| 通道 | 调整 | 保留的内容 |
|---|---|---|
| 左右 sweep | 正侧映射为 −12°～65°，另一侧镜像；延后 0.06 周期 | 原曲线形状；划幅由约 105° 缩至 77° |
| 左右 feather | 原幅度区间仿射映射至 0°～65°；延后 0.06 周期 | 原转平/回正过程和曲线特征 |
| 左右 elevation | 延后 0.06 周期；再施加水面与交叉条件所需的最小修正 | 不满足条件以外的源曲线部分；允许两侧独立修正 |
| 滑座 | 原归一化曲线映射至 −0.22～0.22 m；延后 0.02 周期 | 位移曲线形状和回座过程 |
| 左右肘角 | 原屈肘幅度不缩放；提前 0.02 周期，转换到机器人投影零位与屈曲方向 | 论文屈伸规律及原幅度；右侧仍是左侧曲线映射 |
| T6 躯干倾角 | 原幅度乘 0.85；提前 0.02 周期 | 论文曲线形状；不以 IK 躯干姿态替换 |

周期统一为 3 秒，即 20 桨/min。0.02 周期为 0.06 秒，0.06 周期为 0.18 秒。未用人工平滑函数重写源曲线，也未用 IK 反求结果替换肘角/T6。除 elevation 外，最终曲线与显式幅度/相位变换结果完全一致。

来源：RowIMU 桨角、WiRMS 滑座（DOI 10.3390/s23031060）、Pitto 左肘与 T6（DOI 10.3390/app14199055）。详细来源记录仍保存在 `data/rowing_reference_provenance.json` 和 `data/reference9/`。这些来源并非同步采集，不将其描述为一条原始同步人体记录。

## 实际 reset 与固定握持

reset 选取接近伸肘的回桨阶段（相位 0.920）后单独闭合双手、双脚约束，不要求软参考恰好经过它。双肘接近伸直、稍向外，场景默认关节与 reset JSON 一致。最大等式约束误差约 1.5e-09；没有穿透接触。

固定腕—握柄安装角相对本轮开始版本调整左 9.33°、右 15.65°。旋转围绕握持中心进行，桨柄与套筒保持同轴；weld 不随相位改变。保留先前额外抬高 2 cm 的桨环安装及左高右低 10 mm 的差异。

重新平衡浮重与纵倾：船体升沉 -4.36 mm，纵倾 -0.188°，剩余静态横摇力矩约 0.435 N·m。0.2 秒零动作 reset 检查无终止、无接触，最大横摇约 0.076°；这不是划桨动态稳定性证明。

## 同条件可达性诊断

对原文献基准和调整后参考，使用同一当前装配、同一 IK 目标权重、同一求解器和相位网格，分别拟合辅助姿态；密集检查 1601 个相位。下表顺序均为左 / 右。

| 指标 | 文献基准 | 调整后 |
|---|---:|---:|
| 握持中心位置 RMS，cm | 8.55 / 8.59 | 2.92 / 3.44 |
| 握持中心位置最大误差，cm | 17.60 / 18.04 | 6.15 / 7.57 |
| 握持朝向 RMS，deg | 45.71 / 55.28 | 30.25 / 42.14 |
| 握持朝向最大误差，deg | 78.12 / 136.72 | 48.48 / 92.94 |
| 躯干倾角 RMS，deg | 1.97 | 0.57 |

位置和朝向可达性均有改善，但局部 IK 不是全局最优性或整周期可行性证明。最大残余朝向误差仍较大；本版按软参考约定允许偏差及局部碰撞。调整后辅助姿态最大穿透约 6.5 cm（基准约 5.5 cm），碰撞并未全面改善。物理仿真的真实 weld 和碰撞没有因此关闭。

在固定标定浮态下，稳定 drive 桨叶最高点至少低于水面 3.0 cm；稳定 recovery 桨叶最低点至少高于水面 12.9 cm。回桨高度保留了源 elevation 的特征，没有为贴水而再整段改形。drive 内部为相位 0.11～0.41，recovery 内部为 0.56～0.96；出入水过渡单列，不混同稳定段。

交叉时目标桨柄左高右低至少 3.2 cm；辅助人体姿态中的手部最小高度差约 1.6 cm。收桨时，肘相对肩—腕连线向后约 5.6 cm、向外约 5.5 cm，呈侧后方屈肘。这个连线偏移描述屈曲方向，不等于肘必定位于肩的后方。

## 验证与产物

29 项测试通过，新增检查确保文献形状/原幅度按记录保留，且不会被辅助 IK 覆盖。新 reset、限位、稳定段水位、侧后方屈肘、启动渐入和碰撞传感器检查也通过。没有重跑整周期策略动力学，不能据此宣称滚转稳定。

- `ten_channel_comparison.png` / `.svg`：文献基准、幅度/相位调整、最终十通道叠图。
- `baseline_ten_channels.csv`、`affine_ten_channels.csv`、`adjusted_ten_channels.csv`：三组可审计数值。
- `reset.png`：真实 reset；`reference20.mp4` / `.gif`：无头部、无文字的辅助参考动画。
- `blade_paths.png`：使用指定的 `render_rowimu.py` 更新的双桨轨迹与水面。
- `validation.json`：完整测量；`reset_fit.json`：固定握持和 reset 校准。

运行数据位于 `data/reference20/`。此前人工软参考和硬约束版本保留作历史对照，不再作为当前目标。
