# policy7400 简化水动力模型

本模型面向已有的快速水动力求解器。每 2 ms 输入规定的船桨运动、平水面几何和物理载荷，输出船体、左桨、右桨各自的六分量流体载荷。每个刚体先给出世界坐标系下的力（N），再给出绕自身原点的力矩（N·m）。机器人通过船桨的规定运动影响结果。

## 模型与参数

每个刚体的总载荷等于物理主模型与运动历史残差之和。物理主模型计算船体静水力、湿表面摩擦、其余船体与鳍阻力以及包含转动耦合的附加质量反力。桨侧计算静水力、准定常阻力和升力、随浸水变化的附加质量反力与一项瞬态修正。瞬态修正取桨坐标系准定常升阻载荷减去它的 80 ms 指数平均，再旋转回世界系。它增强迅速建立或消失的载荷，是工程近似，不能从合力单独辨识为某个特定涡结构。

主模型本次仅从 CFD 标定一个标量。船体湿表面摩擦倍率取 1.43215，由前两周期船体纵向黏性力的时间和除以工程摩擦力的时间和得到。升阻力、附加质量和几何沿用工程模型参数。桨侧瞬态增益固定为 1。第三周期将增益重新按训练段拟合后，两桨合力 RMSE 的变化均小于 0.2 N。

运动特征记为 x。对每个选用的分量，残差模型同时接收 x 和 x 减去其 80 ms 指数平均，分别按训练集均值与标准差归一化，再裁至 ±8。滤波器用第一帧初始化。用当步和前一步速度求加速度，对残差输入中的加速度再做 12 ms 因果低通。500 Hz 是模型的更新频率。

| 部件 | 运动输入与约束 | 可学习参数 |
| --- | --- | --- |
| 船体 | 高度，竖直方向在船体 x、z 轴的投影，三向速度，俯仰和偏航角速度，纵向和垂向加速度，俯仰角加速度。对各项及其历史差作仿射组合，经 tanh 输出纵向力、垂向力、俯仰力矩，再旋转至世界系。 | 22×3+3 = 69 |
| 左右桨共享 | 湿面积比、浸深，两项竖直方向投影、两项船首方向投影，桨叶中心三向速度、两项角速度、两项加速度、船体纵向速度。镜像统一左右桨坐标。28 维输入经过 16 单元 tanh 隐层，输出法向、弦向的有界力修正。 | 28×16+16+16×2+2 = 498 |

桨力作用点取投影桨叶的几何面积中心。残差力矩由原点到作用点的力臂叉乘残差力得到。该中心固定在桨体坐标系内，属于简化假设。近水面门控使用最低桨点相对平水面的深度及其历史，允许刚出水后的残差短时衰减。船体的局部横向力、滚转与偏航力矩完全由物理主模型给出。全部 567 个残差参数使用前两周期拟合。船体系数、标准化常数和输出幅值可直接从 hull_coefficients.csv 读取。

## 运行

解压 water_forces_model.zip，在有 NumPy、PyTorch 的 Python 环境中运行随包的 35 帧样例。命令会核对预期结果。

```shell
python replay_model.py
python replay_model.py example.npz --output predicted.npz
```

程序中实例化 final_runtime.WaterForces()。每次独立回放先调用 reset()，每步只调用 step() 或 components() 一次。后者分开返回主模型和残差。连续周期共享滤波历史。输入形状如下。

| 输入名 | 每帧形状 | 定义 |
| --- | --- | --- |
| hull_motion、oar_motion | (1,26)、(2,24) | 工程中 motion_history/prepare_motion.py 定义的因果运动特征。配置文件 ids 选择实际使用的列。 |
| hull_map、oar_map | (1,6,6)、(2,6,6) | 船体旋转，以及包含右桨镜像、力臂和近水面门控的桨映射。 |
| previous_physics | (3,6) | motion_history/prepare_motion.py 中的 base，已含一次 8 ms 因果低通。 |
| friction | (6,) | 乘摩擦倍率前的船体摩擦力与力矩，未低通。 |
| quasi_local | (2,2,3) | 两桨工程升力与阻力之和，在各自实际局部坐标系的力、力矩。 |
| oar_rotation | (2,3,3) | 将各桨实际局部坐标旋转到世界坐标的矩阵。 |

可传自有 NPZ，数组名同上，各数组额外的首维为时间。模型包提供残差权重、物理修正、示例和推理接口。新轨迹的几何、原始物理载荷及运动输入需由已有快速水动力求解器提供。

## 消融和验证

使用 policy7400 一条 11.6 s、5,800 帧的规定运动轨迹。对 CFD 力、力矩做一次 21 点居中平均。输入的物理量与运动历史均只使用当前和过去数据。周期切分在 5.2 s 和 8.4 s 边界的两侧各留至少 20 ms，以隔离居中滤波的标签。先用周期 1 训练、周期 2 选结构，再用周期 1 和 2 重训，报告 t>8.42 s 的结果。周期 3 曾用于此前模型研究。独立策略、不同桨频和双向耦合尚待验证。

1. 对物理主模型单独删除静水力、摩擦、其余船体阻力、附加质量、桨升力、阻力与瞬态项。另行加回原辐射记忆和桨表面摩擦。静水力由相同几何与姿态、零速度重新计算。物理删除试验固定其余参数，检验各项本身的贡献。
2. 对上一版大网络分别移除多帧输入、额外载荷输入、压力监督、黏性残差输出、差分/功率/积分损失、船体摩擦标定、桨侧局部液位或来流修正、桨侧力偶和门控等。各组使用相同训练数据、随机种子和优化预算。船体慢变修正另外用同一权重作前后对比。各表中 full 是该组对照。
3. 简洁架构搜索覆盖无隐藏层、16 或 32 个隐藏单元，当前帧或增加 80 ms 历史，船体 3 或 6 个局部输出，桨侧 2、3 或 6 个输出。周期 2 共 30 种结构，每种 3 个种子。按三种子的中位评分选型，保留符合历史输入要求且距离最佳值 5% 以内、参数最少的结构。交付预设种子 38 的单模型。
4. 对选定架构进行独立配对重训，移除主模型、残差历史、两者同时移除、仅移除主模型修正、各运动输入组、各损失组，也测试 20/240 ms 历史、去除近水面门控与两桨分别训练。移除历史指移除残差分支的指数平均特征，物理方程与门控中的记忆仍按各自定义使用。移除物理指仅保留相同的几何残差映射和输出上限。各组删除测试给出当前结构下的依赖性。

波形评分为按通道标准差归一化的波形 RMSE 加 0.25 倍的 20 ms 增量 RMSE。选型评分另外加入 0.4 倍的归一化纵向平均力偏差和 0.2 倍的归一化平均功率偏差。表内 RMSE 以三向误差平方和的时间均值开方。冲量取世界 x 分量，做功为瞬时功率的时间积分，瞬时功率等于刚体原点线速度与力的点积，加上角速度与力矩的点积。

| --- | ---: | ---: | ---: |
| 船体 | 166.7 / 258.7 | 122.9 / 121.4 | 76.3 / 80.7 |
| 左桨 | 32.8 / 62.3 | 19.7 / 35.6 | 21.6 / 41.2 |
| 右桨 | 33.6 / 63.6 | 17.6 / 32.3 | 10.6 / 20.1 |

| CFD 纵向冲量（N·s） | −194.6 | 45.7 | 70.6 |

第三周期船体横向力相关系数 0.48，为 18 个分量中最低。左桨的合力和力矩误差低于上一版，右桨和船体误差较高。18 通道正负峰按 CFD 峰显著度 15% 极差和 100 ms 匹配窗配对。简洁模型检出 137 个峰谷，匹配 117 个 CFD 峰谷中的 101 个，匹配时差中位数 8 ms。上一版对应 125、104 和 4 ms。液位、来流、压强和黏性残差的独立预测均已从部署模型去除；紧凑模型的输出解释为这五个局部广义力修正。

全部逐项结果在 ablation.csv，原始及平滑 CFD 误差、各轴相关性、峰谷、冲量和做功在 validation.json。comparison.npz 保留双周期逐时刻的模型和 CFD 曲线。逐帧重放完整的 5,800 个输入帧，第三周期输出与批量评估的最大分量差为 0.000192（各分量采用 N 或 N·m）。样例包含初始化后的前 35 帧。
