# 紧凑套筒手设计

用于替代 H2 原有夹爪的刚性握桨连接件，左右手共用几何。套筒轴线与桨柄轴线重合，连接柱沿套筒径向连接至手腕安装面。

## 尺寸（mm）

| 项目 | 尺寸 |
|---|---:|
| 套筒内径 | 34 |
| 套筒外径 | 50 |
| 套筒轴向长度 | 70 |
| 套筒名义壁厚 | 8 |
| 连接柱直径 | 50 |
| 连接柱外露长度（安装面到套筒最近外壁） | 4 |
| 连接柱建模毛坯长度（含接合重叠，随后融合并贯通内孔） | 20 |
| 安装面到桨柄轴线 | 29 |
| 套筒两端外缘圆角 | R2 |
| 套筒两端内孔口圆角 | R1 |
| 连接柱与套筒接合圆角（设计初值） | R5 |

连接柱外露长度按用户要求为 4 mm，接合圆角沿用 R5。34 mm 内孔贯通，不被连接柱堵塞。

坐标约定：X=0 是手腕安装面，+X 指向桨柄；桨柄轴线为 X=29、Y=0、沿 Z 方向。CAD/STEP 使用 mm，仿真 STL/GLB 使用 m。

仓库握持位置的桨柄截面外包尺寸约 33.4 mm，因此 34 mm 是有间隙的包络孔，不能靠该几何自行保证抗滑移和传递羽化力矩。仿真仍应使用六维 weld 表示刚性握持；实际制造需要另行确定锁紧方案、安装孔位、材料和公差。

已替换 scene.xml 和 preview.xml 的两只手，并重新求解双臂与双桨姿态。为兼容既有连接命名，手部 body 仍名为 left/right_dex1_base_link，但原手指和夹爪网格已移除。训练碰撞采用 16 个环向盒体加连接柱的近似，保留 34 mm 内孔，不使用填满内孔的单凸包。桨柄及远处粗套环分开建立碰撞几何。

## 文件与验证

- `compact_hand.step`：带真实曲面的单一 CAD 实体，单位 mm。
- `compact_hand.stl`：融合后的封闭网格，单位 m。
- `assembly.glb`：同一几何的查看文件，单位 m。
- `preview.png`：三维预览及从实体网格提取的中心剖面。
- `dimensions.json`：尺寸与几何验证结果。
- `generate.py`：参数化生成脚本；依赖 CadQuery、trimesh、NumPy、Matplotlib。

已验证 CAD 实体有效且只有一个 solid，导出网格封闭且面方向一致，直径 33.98 mm 的检查圆柱可贯通内孔。交线采用 R5 实体圆角；连接柱远端边缘预先倒 R5，以避免两个等径圆柱相交时的相切退化。

## 装配姿态

`pose_baseline.json` 保存用户指定的肘轴方向约束基准；`pose_report.json` 保存新关节角和误差。左右握持位置均为桨局部轴向绝对坐标 0.785 m，套筒覆盖 0.750–0.820 m，位于桨柄实际区间 0.74425–0.86216 m 内。每侧肘轴方向变化 4.95°，小于 5°。相对最大伸展位置的肘关节弯曲约为左 3.72°、右 5.00°。

最大伸展是肩部末级锚点—肘锚点—腕部首级锚点连线夹角最小时的肘关节位置；因连杆偏置，最小几何夹角约 18.98°，并非肘屈曲角。腕部纵轴相对前臂连线仍偏转约左 18.65°、右 27.68°，是在握持闭合、肘轴限幅及现有固定安装方向下的数值优化结果，不保证全局最优。

使用 `python tools/fit_compact_hand.py --apply` 重新求解并写入两个 XML，不带 `--apply` 只生成求解报告。单手质量约 0.2402 kg，质心和完整惯量来自封闭几何、假设均匀铝材密度 2700 kg/m³。`installed_pose.png` 为实际 MuJoCo 装配渲染。
